# Changelog

All notable changes to NexoSync are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).
Snapshot versions (`v1`, `v2`, …) are **your content**, not the plugin — they are never listed here.

## [Unreleased]

## [1.0.2] - 2026-11-20

### Added

- Single files can now be synchronized. List them under `sync.paths` by name, for example
  `inventory.yml`, alongside directories such as `items`.

### Changed

- Nexo is now a hard dependency: NexoSync is not enabled on a server without Nexo.

## [1.0.1] - 2026-10-30

### Fixed

- Known issues fixed.
